# 顺路旅行

导入旅行攻略、核对每日路线、查景点门票，并按行程挑选住宿。

## 本地复现

1. 使用 Node.js 22 或以上版本，在仓库根目录运行 `npm ci`。
2. 复制 `.env.example` 为 `.env`，在本机填写百炼、高德和 FlyAI Key。Managed Agent 排序可按需配置。
3. 运行 `npm start`，访问 [本地行程工作台](http://127.0.0.1:8790/guide)。
4. 点「新建计划」，导入攻略并创建行程。切换每天看路线，点开景点查门票，或进入「按行程推荐酒店」。

运行 `npm test` 可执行本地自动化测试。
